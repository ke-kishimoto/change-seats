# 席替えアプリ

研修生を入力し、ランダムに最大4人ずつのグループへ配置するStreamlitアプリです。現在、所属やその他の属性は席割りに影響しません。

## 起動方法

Python 3.10以降を用意し、プロジェクトフォルダーで次を実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

表示されたURLをブラウザで開きます。終了するときは、実行中のターミナルで `Ctrl+C` を押します。

## 使い方

1. 「企業一覧」に企業名を入力してEnterで追加します。研修生の所属欄では登録した企業を選べます。企業一覧から削除しても、研修生に設定済みの所属は残ります。
2. 表に研修生を入力します。表の下の「＋」から行を追加できます。不要な行は選択して削除できます。
3. 名前をすべての行に入力します。同姓同名も入力できます。その他の項目は任意です。
4. 「ランダムに席替え」を押すと、入力人数と同じ数の席に1人ずつ配置します。4人に満たない端数は最後のグループになります。
5. もう一度ボタンを押すと、再びランダムに席替えします。偶然同じ結果になることもあります。

成績はA〜E（Aが最も良い）、コミュニケーションスキルは「積極的」「どちらでもない」「消極的」から選びます。どちらも空欄にできます。保存時は成績をA=5〜E=1、コミュニケーションを積極的=1、どちらでもない=0、消極的=-1の数値で保持します。これらの数値は将来の処理に利用できますが、現時点では席割りに使用しません。

### 研修生情報の保存・読み込み

- 「ブラウザに保存」を押すと、企業一覧と現在の表をブラウザのローカルストレージに保存します。自動保存ではありません。入力を変更した後も、再度保存が必要です。以前保存した研修生情報も読み込め、所属名が企業一覧に追加されます。
- リロード後は「ブラウザから読み込み」を押すと、保存した表を復元できます。現在の表は置き換わり、席替え結果は消去されます。
- 「ブラウザの保存データをクリア」は保存データだけを削除します。画面の入力は残り、再度保存できます。
- ローカルストレージは同じブラウザ・同じURLのオリジン（プロトコル・ホスト・ポート）で利用できます。別のブラウザや端末では共有されず、ブラウザの設定や閲覧データの削除で消えることもあります。
- 席替え結果はブラウザの保存データに含まれません。保存データには研修生の個人情報が含まれます。

## 構成

- `app.py`: 入力画面と結果表示
- `seating.py`: ランダムな席割り処理。将来の最適化処理を追加する際にも画面と分けて扱えます。
- `trainee_file.py`: ブラウザに保存する研修生情報の変換と読み込み時の検証
- `local_storage_component/index.html`: ブラウザのローカルストレージを操作する画面
